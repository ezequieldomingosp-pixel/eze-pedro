Activité 2

Atelier pro 1 (Bodin) : pingage entre les différents postes

Intitulé
Configuration IP de quatre machines virtuelles et tests de communication par ping
Contexte
Atelier professionnel : mise en réseau de deux routeurs, d'un poste Linux et d'un poste Windows, puis vérification de la connectivité entre eux et vers Internet.
Période
[dates]
Outils
VirtualBoxDebianWindows 10nanopingConfiguration IP statique

Objectif

Configurer les interfaces réseau de chaque machine, puis vérifier avec la commande ping que tous les postes communiquent entre eux et que le routeur prestataire accède à Internet.

1. Le routeur prestataire

Sous Debian, la configuration réseau se fait en ouvrant le fichier des interfaces avec nano :

nano /etc/network/interfaces

Ce routeur possède deux cartes : une carte NAT (enp0s3, en DHCP) pour accéder à Internet, et une carte réseau interne (enp0s8) en IP statique 192.168.16.253, masque 255.255.255.0.

Une fois les informations saisies, il faut appliquer les modifications en redémarrant le service réseau :

Tests de ping depuis le routeur prestataire

2. Le routeur interne

Même méthode avec nano /etc/network/interfaces. Ce routeur possède une carte en pont (enp0s3, 172.19.200.16, masque 255.255.0.0) et une carte réseau interne (enp0s8, 192.168.16.254, masque 255.255.255.0).

Tests de ping depuis le routeur interne

Le ping vers la machine extérieure échoue (100 % de paquets perdus) : cette machine n'est pas joignable depuis ce réseau à ce stade de l'atelier.

3. Le poste Linux

Ce poste n'a qu'une carte réseau interne (enp0s3) en IP statique 192.168.16.20, masque 255.255.255.0. Le redémarrage du service réseau applique la configuration.

4. Le poste Windows : changer l'adresse IP

  1. Ouvrir Réseau et Internet.
  2. Ouvrir le Centre Réseau et partage.
  3. Cliquer sur Modifier les paramètres de la carte.
  4. Ouvrir l'état de la carte Ethernet, puis ses propriétés.
  5. Dans Protocole Internet version 4 (TCP/IPv4), choisir « Utiliser l'adresse IP suivante » : 192.168.16.10, masque 255.255.255.0. Cocher « Valider les paramètres en quittant » pour enregistrer.
  6. Tester dans l'invite de commandes avec ping 192.168.16.253.

Résultat

Toutes les machines du réseau interne 192.168.16.0/24 se joignent entre elles, et le routeur prestataire accède à Internet grâce à sa carte NAT. Le poste Windows joint bien le routeur prestataire (0 % de perte). Le seul test qui échoue est le ping du routeur interne vers la machine extérieure 172.19.200.18.
