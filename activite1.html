Activité 1

Plateforme de TP virtualisée du BLOC 2 (SIO1, option SISR)

Intitulé
Plateforme de TP virtualisée du BLOC 2
Contexte
Mise en place progressive d'une infrastructure réseau complète à partir de machines virtualisées, en 5 phases.
Période
[dates]
Outils
Machines virtuelles (vmnet)DebianWindowsDHCPDNSSSHHTTP / HTTPSFTPProxyPare-feu

Objectifs

Mettre en place une plateforme virtuelle progressive, à base de machines virtualisées, en cinq phases :

  1. Phase 1 : création d'un réseau LAN (un serveur et une station)
  2. Phase 2 : passerelle vers Internet
  3. Phase 3 : routage entre plusieurs réseaux internes
  4. Phase 4 : applicatifs divers
  5. Phase 5 : DMZ

Plan d'adressage

Phase 1 : un serveur et une station

  • Installation d'un premier serveur de base (Debian) : SRVLAN1
  • Installation d'une station Windows : CLIENT1
  • Paramétrage réseau de base (IP) et des systèmes (mises à jour)
  • Mise en place d'un serveur DHCP de base pour les réseaux internes
  • Mise en place d'un serveur DNS cache (vis-à-vis de l'extérieur)

Phase 2 : passerelle Internet

Séparation du réseau interne et du réseau externe par une passerelle dédiée, PASSFRW, qui fait office de routeur (puis de pare-feu et de proxy par la suite). Ajout d'un deuxième serveur, SRVLAN2, avec un deuxième serveur DNS.

Phase 3 : routage entre réseaux internes

  • Mise en place d'un routeur interne, ROUTEUR1
  • Séparation du réseau des serveurs et du réseau des stations
  • Routage général entre les réseaux (internes et extérieur)
  • Configuration DHCP avec relais
  • Mise en place de zones DNS internes

Phase 4 : applicatifs divers

Installation et paramétrage des principaux services côté serveurs : DNS internes (résolution directe et inverse), DHCP avec relais, Web HTTP et HTTPS, FTP, SSH.

Phase 5 : réseau DMZ

  • Mise en place d'une DMZ simple
  • Serveurs bastions
  • Services applicatifs pour l'extérieur (HTTP / HTTPS)
  • Services de rebond pour l'intérieur (DNS, proxy)
  • Sécurisation du réseau sur les pare-feux

Rôles des serveurs

SRVLAN1

  • Serveur DHCP
  • Serveur DNS primaire
  • Serveur SSH

SRVLAN2

  • Serveur DNS secondaire
  • Serveur HTTP / FTP
  • Serveur SMTP / POP / IMAP
  • Serveur SSH

ROUTEUR1

  • Routage IP
  • Relais DHCP pour le réseau des stations
  • Serveur SSH

PASSFRW

  • Serveur DNS cache (Internet)
  • Pare-feu de réseau
  • Serveur SSH

SRVDMZ

  • Serveur HTTP / FTP (Internet)
  • Service proxy
  • Service DNS de rebond
  • Serveur SSH
